The standard action control — at most one \`primary\` per screen, everything else secondary or quiet.

\`\`\`jsx
<Button variant="primary" icon="plus">Log a weigh-in</Button>
<Button variant="secondary" iconRight="download">Export CSV</Button>
<Button variant="quiet" size="sm">Cancel</Button>
\`\`\`

Labels are sentence case and name the action's object ("Log a weigh-in", not "Submit"). Never colour a button by outcome.
